# Nachhaltigkeits-Erfassung

Erfassung nachhaltiger Alltagshandlungen und größerer Aktionen (Aufgabe §8,
[life-areas.md](./life-areas.md) §4.3).

## Aktionstypen

- **Alltagshandlungen** (`daily_block`): Mobilität (Fahrrad statt Auto, zu Fuß statt
  motorisiert, ÖPNV, Fahrgemeinschaft, unnötige Fahrt vermieden), Ressourcen (Mehrweg,
  Verpackung vermieden, Müll getrennt, Strom/Wasser gespart), Einkauf (saisonal/regional,
  nachhaltigere/pflanzliche Alternative), Teilen/Leihen.
- **Größere Aktionen** (`special_action`): Second-Hand gekauft, repariert statt ersetzt,
  Gegenstand weitergegeben, unnötigen Kauf vermieden, Lebensmittel gerettet (größere Menge),
  nachhaltiges Haushaltsprojekt abgeschlossen.

Die Erfassung erfolgt als Ritual-Check-in (eine oder mehrere Handlungen je Gruppe). Die
Trennung daily/special dient der späteren spielerischen Einordnung; in Phase 3 wird nichts
bewertet.

## Fachliche Präzision (Aufgabe §8.2)

**Keine** erfundene ökologische Exaktheit: keine kg CO₂, keine Wasser-/Energie-Zahlen, keine
pauschalen Geldersparnisse, keine wissenschaftlich unbelegten Scores. Handlungen werden
qualitativ dokumentiert.

## Abgrenzung / Doppelzählung

Eine Handlung, die bereits Teil eines Ernährungs-Check-ins ist (z. B. „pflanzliche
Alternative"), erzeugt **nicht automatisch** einen zusätzlichen Nachhaltigkeitseintrag. Jede
reale Handlung hat genau **eine** primäre Kategorie ([double-counting-rules.md](./double-counting-rules.md)).
Fahrrad/ÖPNV/zu Fuß: entweder Bewegung **oder** Nachhaltigkeit pro Weg.
